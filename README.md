# NetSuite Senior Developer Interview Assignment

## 1. Project Overview

This repository contains my implementation of the NetSuite Senior Developer interview assessment.

The solutions are developed using SuiteScript 2.1 and NetSuite SuiteCloud Development Framework (SDF).

## 2. Technologies Used

- NetSuite ERP
- SuiteScript 2.1
- SuiteCloud Development Framework (SDF)
- JavaScript
- Visual Studio Code
- Git and GitHub

## 4. Implementation

The assignment covers the following areas:

- Vendor Bill Payment Map/Reduce implementation.
- Sales Order review and follow-up Task creation.
- Email invoice functionality using Suitelet and Client Script.

## 5. Deployment

The project was validated and deployed to a NetSuite demo account using SDF.

The SuiteCloud extension in Visual Studio Code was used for project validation and deployment.

## 6. Testing and Documentation

Testing scenarios, test results, assumptions and relevant assignment documentation are maintained in the `Docs` folder.

## 7. AI Usage Disclosure

GitHub Copilot was used to assist with script conversion.

The generated code was reviewed, corrections were made, and the implementation was tested.

All submitted code was reviewed and understood before submission.



## 8. Submission

All assignment development is maintained in the `dev` branch.

The Pull Request from `dev` to `main` is submitted for interview team review and intentionally left open without merging.
